## Application Architecture

```
Browser
  └─→ ACME CLOUD Ingress (HTTPS termination)
        └─→ nginx:80
              └─→ React SPA (pre-compiled static files in /usr/share/nginx/html)
```

- No backend, no database, no external API calls
- All routing handled client-side via nginx `try_files` SPA fallback
- No environment variables required at build or runtime

---

## Docker Architecture

```
Stage 1 (build):  node:20-alpine
  - npm ci (from package-lock.json)
  - npm run build  →  dist/

Stage 2 (runtime): nginx:alpine
  - COPY dist/ → /usr/share/nginx/html
  - COPY nginx.conf → /etc/nginx/conf.d/default.conf
  - EXPOSE 80
  - CMD nginx -g "daemon off;"
```

Final image contains **no Node.js or npm**.
